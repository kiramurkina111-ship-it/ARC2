What it is

A control plane for AI agents with money

The vault sits between the user, the agent, and service providers. Safe vendor payments execute immediately. Risky actions become approval requests.

01

Run

Create repeatable tasks with a vendor, expected spend, and a bounded run budget.

02

Control

Enforce approved vendors, per-action limits, daily caps, and owner review.

03

Settle

Keep the result, policy decision, metadata hash, and payment receipt together.

1 User defines a run

Task brief, vendor, planned spend, and a hard USDC budget.

2 Agent checks constraints

Vault balance, allowlist, action ceiling, and daily budget.

3 Vault settles or pauses

Allowed spend executes. Risky spend waits for owner approval.

4 Result stays auditable

The artifact, receipt, and Arc transaction stay linked to the run.
